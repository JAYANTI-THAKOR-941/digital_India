# Digital India

Full-stack project with product and user models, API routes, and a React home and registration interface.

## Project structure

- `backend/`
- `frontend/`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/digital_India.git
cd digital_India
```

Install dependencies in both directories, configure the database and API endpoint, start the backend using its scripts, and run the frontend development server.

## Security

A `.env` file is tracked in this repository. Rotate any real credentials it contains, use ignored local environment files, and never publish secret values.
